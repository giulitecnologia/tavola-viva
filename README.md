# Tavola viva

Tavola da disegno tecnico pensata per la LIM: foglio a quadretti con squadratura, righello, riga, squadre 45° e 30°/60°, compasso, matite 2H e HB, lettere e moduli, passaggi registrati da mostrare fase per fase.

È un'unica pagina HTML, senza dipendenze esterne: basta aprire `index.html` nel browser.

I disegni vengono salvati nel browser (localStorage) del dispositivo in uso. Per conservarli o trasferirli, usa "Tavole → Scarica file della tavola".
